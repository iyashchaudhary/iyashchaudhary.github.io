How to publish this entry:
1. Copy the code below.
2. Open entries-data.js in your site files (github.com → your repo → entries-data.js → pencil icon).
3. Paste it as a new object at the end of the UNFILTERED_ENTRIES array — right above the closing ];.
4. Put a comma , after the closing } of the entry before it.
5. If you added a photo, upload that image file into the same folder.
6. Click Commit changes. Done — the new day appears automatically within a minute or two.

Editing rule: after generating, open entries-data.js, find the SAME old day block (search its date), delete that whole block and paste the new one in its place. Keep the comma after it. Same Commit changes step as always.
